## English

First preview of Layout-Aware Search for PowerToys Command Palette.

- Find ChatGPT by typing `срфепзе`; conversion also works in the opposite direction and across other loaded Windows keyboard layouts.
- Search Start Menu shortcuts and current-user MSIX/Store apps.
- Launch the best match from the main search fallback, or open all matches on the extension page.

### Install without compiling

1. Install PowerToys with Command Palette enabled.
2. Download **LayoutAwareSearch-0.1.0-x64.zip** for Intel/AMD PCs or **LayoutAwareSearch-0.1.0-ARM64.zip** for Windows on ARM.
3. Extract the ZIP completely and open **Install.cmd**.
4. This preview uses a **self-signed certificate**. Compare its fingerprint below, type **YES** if you choose to trust it, and accept the administrator prompt. Certificate trust is needed once; the application is installed for your original Windows user.
5. Restart Command Palette, then enable **Layout-Aware Search** and its **Search apps in other keyboard layouts** fallback.

No Visual Studio, compilation or .NET SDK is needed. The .NET runtime is included. Updates are manual. If an old Visual Studio development copy using the Microsoft template publisher is installed, uninstall that copy first.

This is a preview: application search and installer checks are automated; interactive Command Palette behavior and execution on an ARM64 device still need user validation. IME and composed dead-key sequences are not reconstructed.

## Русский

Первая предварительная версия Layout-Aware Search для PowerToys Command Palette.

- Поиск ChatGPT по запросу `срфепзе`; преобразование работает и в обратную сторону, а также между другими загруженными раскладками Windows.
- Поиск ярлыков меню «Пуск» и приложений MSIX/Store текущего пользователя.
- Запуск лучшего совпадения через fallback основного поиска или просмотр всех результатов на странице расширения.

### Установка без сборки

1. Установите PowerToys и включите Command Palette.
2. Скачайте **LayoutAwareSearch-0.1.0-x64.zip** для Intel/AMD или **LayoutAwareSearch-0.1.0-ARM64.zip** для Windows на ARM.
3. Полностью распакуйте ZIP и откройте **Install.cmd**.
4. Эта версия подписана **самоподписанным сертификатом**. Сравните его отпечаток ниже; если согласны доверять ему, введите **YES** и подтвердите запрос администратора. Доверие устанавливается один раз, а само приложение — для исходного пользователя Windows.
5. Перезапустите Command Palette, включите **Layout-Aware Search** и его fallback **Search apps in other keyboard layouts**.

Visual Studio, сборка и .NET SDK не нужны: среда выполнения .NET включена. Обновления устанавливаются вручную. Если установлена старая копия из Visual Studio с шаблонным издателем Microsoft, сначала удалите её.

Это предварительный выпуск: автоматические проверки покрывают поиск и установщик; работу интерфейса Command Palette и запуск на ARM64-устройстве ещё нужно подтвердить пользователям. IME и составные последовательности dead keys не восстанавливаются.
