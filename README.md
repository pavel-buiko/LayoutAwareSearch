# Layout-Aware Search

Расширение PowerToys Command Palette для поиска приложений независимо от раскладки ввода.

- `срфепзе` находит **ChatGPT**.
- `,kjryjn` находит **Блокнот**, если приложение с таким названием есть в индексе.
- Исходный запрос тоже участвует в поиске. Регистр не учитывается.
- Проверяются все пары загруженных в Windows раскладок, в обоих направлениях. Список раскладок обновляется при каждом запросе; таблица русских/английских букв не зашита в код.

## Использование

Соберите и разверните проект расширения из Visual Studio с поддержкой MSIX (конфигурация `Debug`, платформа `x64` или `ARM64`). В настройках расширений Command Palette включите **Layout-Aware Search** и его fallback **Search apps in other keyboard layouts**. Если веб-поиск располагается выше результата приложения, измените порядок fallback-команд в настройках Command Palette.

Введите название прямо в основном поле Command Palette. Fallback предлагает запуск лучшего совпадения; при нескольких совпадениях контекстная команда **Show all matches** открывает полный список. Также можно открыть **Layout-Aware Search** и искать на странице расширения.

Расширение использует публичный механизм fallback SDK и не изменяет встроенный поиск Apps. Доступность fallback в основном поле определяется самим Command Palette. Отдельная страница расширения всегда выполняет собственный поиск.

Индекс содержит ярлыки `.lnk`/`.appref-ms` из пользовательского и общего меню «Пуск», а также приложения MSIX/Store текущего пользователя. Обновляется при следующем поиске через две минуты после предыдущего обновления. Переносимые приложения без ярлыка в меню «Пуск» автоматически не добавляются.

Преобразование использует физические клавиши Windows (`VkKeyScanExW`, `MapVirtualKeyExW`, `ToUnicodeEx`), включая Shift/AltGr. Текущая раскладка не переключается, состояние клавиатуры не изменяется. Составные последовательности dead keys и ввод через IME не восстанавливаются; неподдающиеся преобразованию символы сохраняются. Поиск проверяет исходный запрос и преобразования строки между каждой парой раскладок, без перебора отдельных раскладок для каждой буквы смешанного запроса.

## Сборка и проверки

Нужны Windows и .NET SDK с поддержкой целевой платформы проекта .NET 9 / Windows SDK 26100.

```powershell
dotnet build LayoutAwareSearch\LayoutAwareSearch.csproj -p:Platform=x64
dotnet run --project LayoutAwareSearch.Tests\LayoutAwareSearch.Tests.csproj -p:Platform=x64
```

Проверки не требуют стороннего тестового фреймворка. Проверяются ранжирование, исходный запрос, пустой ввод, Unicode, индексирование реальных приложений Windows и преобразования между загруженными раскладками US/RU. Если эта пара отсутствует, соответствующие проверки пропускаются. Проверки не добавляют раскладки, не запускают приложения и не устанавливают расширение.

Полная интеграционная проверка требует доступа к установленным пакетам Windows. Для ограниченной песочницы можно добавить `-- --skip-package-checks`: проверка наличия MSIX-приложений будет явно пропущена, остальные проверки продолжат выполняться.

Документация API: [fallback в Command Palette](https://learn.microsoft.com/en-us/windows/powertoys/command-palette/microsoft-commandpalette-extensions/ifallbackhandler), [преобразование клавиш Windows](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-tounicodeex).
